## 실습 자료 사용 전 확인

- AWS 리전은 별도 안내가 없다면 서울(`ap-northeast-2`)을 사용합니다.
- 화면 자료의 리소스 이름과 식별자는 예시 환경의 기록입니다. 자신의 실습 환경에서 생성된 값을 사용하세요.
- AWS 액세스 키, 비밀번호, 세션 토큰을 코드나 제출물에 기록하지 않습니다.
- 비용이 발생하는 EC2, SageMaker AI, ECR, CloudWatch 등의 리소스는 실습 종료 절차에 따라 정리합니다.
