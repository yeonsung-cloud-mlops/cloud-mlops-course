# 클라우드 MLOps 라이브 클래스룸

강사용 단말에서 학생용 수업 화면을 실시간으로 제어하는 Cloudflare Workers 기반 수업도구다. 1주차는 64장 전체를 웹 고유 콘텐츠로 제공하며, 학생의 선택·입력·체크 결과가 강사 화면에 실시간으로 모인다. 나머지 주차는 기존 자료를 웹 화면으로 이관한 상태다.

- 학생 접속 주소: `https://0060.kr`
- 강사 수업 관리: `https://0060.kr/instructor`
- 보조 접속 주소: `https://www.0060.kr`
- 비상용 Workers 주소: `https://cloud-mlops-live-classroom.hexai.workers.dev`

## 화면

- 공개 루트(`/`): 학생의 여섯 자리 수업 코드 입력만 제공하며 수업 생성 기능은 노출하지 않음
- 강사 포털(`/instructor`): 별도 강사 접근 코드로 인증한 뒤 새 수업 생성, 진행 중 수업 목록 확인, 강사 재참여, 기존 수업 등록
- 강사 제어용: 왼쪽에서 주차·장표·권장 시간·현재 시각·타이머를 확인하고 수업을 제어
- 강사 제어용 오른쪽: 이름 기반 출석, 접속 상태, 장표 확인·완료·답안·질문 수와 참여도 확인, 출석 CSV 저장, Q&A 답변
- 강사 PT용: 프로젝터 전용 16:9 화면, 학생 접속 주소·수업 코드·완료 현황과 공개된 학생 응답 표시
- 학생용: 이름과 수업 코드로 출석, 실시간 장면 동기화, 선택·입력·체크리스트·API 체험·첨부파일·AWS 콘솔 링크, Q&A 질문과 답변 확인
- 이름과 참여 기록은 강사 화면에서만 확인한다. 강사가 PT 공개를 선택해도 학생 이름은 숨기고 답안만 표시한다.

## 콘텐츠 현황

- 01주차 64장 · 02주차 37장 · 03주차 36장
- 04주차 36장 · 05주차 35장 · 06주차 37장
- 07주차 37장 · 08주차 72장 · 09주차 31장
- 10주차 68장 · 11주차 51장 · 12주차 46장
- 13주차 47장 · 14주차 42장 · 15주차 47장
- 합계 686장

1주차 64장은 `public/interactive-content.js`에서 직접 구성한다. 각 장표에는 권장 시간이 지정되어 있으며 1~4교시가 각각 50분, 총 200분이다. AWS 실습 화면과 첨부파일은 `public/assets/week01/`, `public/downloads/week01/`에서 제공한다.

2~15주차의 기존 이관 자료는 `scripts/import-course.mjs`와 `scripts/render-course.mjs`로 갱신한다. 1주차 수업 진행에는 PPTX나 렌더링 이미지가 필요하지 않다.

## 구조

- Cloudflare Workers Static Assets: 강사용·학생용 웹 화면
- Durable Objects: 수업 세션별 상태와 접속자 관리
- Hibernatable WebSockets: 실시간 장면 전환과 낮은 유휴 비용

## 실행

```bash
npm run dev
npm run check
npm run deploy
```

수업 세션과 강사 포털의 진행 중 수업 목록은 생성 후 12시간 동안 유지된다. 강사용 URL의 `key` 값과 `INSTRUCTOR_ACCESS_CODE`는 학생에게 공유하지 않는다. 강사 접근 코드는 Cloudflare Worker Secret으로 설정한다.

학생 이름, 출석 시각, 장표 확인·완료·답안·질문 기록은 해당 수업의 Durable Object에만 저장되며 수업 세션 만료 시 함께 삭제된다. 학생 이름은 URL, 공개 PT 화면, Git 저장소에 기록하지 않는다.
