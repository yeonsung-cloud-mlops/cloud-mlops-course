## 핵심 개정 내용

- 14주 교안·PPT를 15주로 통일하고, 9주차에 `프로젝트 통합·보강`을 신설했다.
- 번역체와 지나치게 강한 표현을 줄이고, 학생이 실습 순서와 제출물을 바로 이해하도록 다듬었다.
- NCS 수행준거를 실습 행동과 증거 자료로 다시 매핑했다.
- AWS 사용자 접속은 IAM Identity Center·역할·임시 자격 증명을 우선하고, GitHub Actions는 OIDC 방식으로 통일했다.
- 주차별로 AWS 콘솔 직접 링크, 메뉴 이동 경로, 확인 항목, 구성도, 공식 문서 링크를 추가했다.
- SageMaker AI 엔드포인트 정리, Bedrock 모델 액세스, CloudWatch 대시보드, AWS 인증 자격증 변경 내용을 2026년 기준으로 반영했다.

## 수업 전 확인

- 교무처가 적용하는 NCS 기준 연도와 버전을 확인한다. 이 개정본은 학교가 보유한 PDF와의 추적성을 위해 기존 코드를 유지했다.
- AWS 콘솔 화면은 바뀐 수 있으므로 스크린샷의 버튼 위치보다 메뉴 이름과 리소스 상태를 기준으로 안내한다.
- 실습 전 서울 리전, 학생 역할, 예산 알림, 종료 시 삭제할 리소스를 강사 계정에서 먼저 점검한다.
