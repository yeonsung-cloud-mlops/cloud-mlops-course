# 1주차 후킹 데모 실행

1. `index.html`을 Chrome, Edge 또는 Safari로 연다.
2. 학생들에게 먼저 중고 가격을 말하거나 휴대폰 메모장에 적게 한다.
3. 새 제품 가격, 사용 기간, 배터리 성능, 외관 상태를 바꾼다.
4. **예상 가격 보기**를 누른다.
5. 오른쪽의 가격과 JSON 응답을 가리키며 사용자 화면과 API 응답의 차이를 설명한다.

인터넷 연결과 AWS 리소스 없이 실행되는 첫 수업용 체험 페이지다. 예측값은 개념 설명을 위한 단순 계산 결과이며 실제 거래 가격을 보장하지 않는다.
