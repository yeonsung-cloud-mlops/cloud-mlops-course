# 클라우드 MLOps 팀 시작 키트

1주차 팀빌딩 활동에서 사용하는 파일이다. 팀원과 함께 아래 순서로 작성한다.

1. `TEAM_REGISTRATION.md`: 팀 이름과 팀원 등록
2. `TEAM_CHARTER.md`: 답장·결정·일정·충돌 규칙 합의
3. `ROLE_ROTATION.csv`: 15주 역할 순환 계획
4. `PROJECT_IDEA_CARD.md`: 3주차에 검토할 프로젝트 후보
5. `INDIVIDUAL_CONTRIBUTION.md`: 개인별 커밋·시연·리뷰·문제 해결 기록
6. `TOPIC_CATALOG.md`: 배포 가능한 예시 주제 8개와 선정 기준
7. `COURSE_ROADMAP.md`: 15주 팀 결과물과 개인 증거 로드맵

## 제출

팀 대표가 작성한 파일 4개를 LMS `1주차 → 팀 등록`에 제출한다.

- `TEAM_REGISTRATION.md`
- `TEAM_CHARTER.md`
- `ROLE_ROTATION.csv`
- `PROJECT_IDEA_CARD.md`

제출한 파일은 팀원 전원이 다시 확인한다.

## 중요한 보안 규칙

AWS 액세스 키, 비밀 키, 세션 토큰, 비밀번호를 이 파일이나 Git 저장소에 적지 않는다. AWS 계정을 서로 공유하지 않고, 각자의 수업용 역할로 접속한다.
