# 젠스파크 주차별 업로드 패키지

이 폴더의 `weekNN` 디렉터리와 같은 이름의 ZIP 파일은 젠스파크에서 주차별 PPT를 다시 만들 때 사용하는 자료 묶음이다.

## 패키지 구성

- `00_젠스파크_15주_콘텐츠브리프.md`: 전체 제작 원칙과 해당 주차 전달 내용
- `01_해당주차_상세교안.md`: 개념, 강의 멘트, 실습 절차, 체크포인트
- `02_NCS_매핑표.md`: 능력단위요소와 수행 증거
- `03_AWS_NCS_교차검증.md`: AWS·NCS 검증 기준
- `04_학생파일_배포수령_가이드.md`: 주차별 배포 파일명·수령·검증·제출 방법
- `05_팀빌딩_학생장표_콘텐츠.md`: 1주차 35~40분 팀빌딩 활동 원고(주차 1에만 포함)
- `06_학생용_15주_프로젝트_로드맵.md`: 매주 학생 행동·팀 결과물·개인 증거·M1~M4 기준
- `07_실습프로젝트_예시주제_학생가이드.md`: 배포 가능한 예시 주제 8개와 선정·확정 기준(1·3주차에 활용)
- `screens/`: 해당 주차에 실제로 수행하며 촬영한 AWS 화면 전체
- `official-reference/`: 해당 서비스의 AWS 공식 문서 참고 화면
- `practice/`: 해당 주차에 별도 실습 파일이 있는 경우 포함

## 젠스파크에 전달하는 방법

1. 한 번에 한 주차만 작업한다.
2. 해당 `weekNN.zip`을 업로드한다. 압축 파일을 읽지 못하면 같은 이름의 폴더를 열어 내부 파일을 모두 업로드한다.
3. 아래 요청문에서 주차 번호와 주제만 바꿔 사용한다.

> 첨부 자료를 근거로 클라우드 MLOps NN주차 수업 PPT를 제작해 주세요. `00_젠스파크_15주_콘텐츠브리프.md`의 공통 제작 지시와 NN주차 부분을 우선 적용하고, 세부 설명은 `01_해당주차_상세교안.md`를 따르세요. `04_학생파일_배포수령_가이드.md`의 해당 주차 파일명과 6개 배포·수령 장표를 실습 전에 넣으세요. 1주차는 `05_팀빌딩_학생장표_콘텐츠.md`의 활동 장표를 본문에 반영하세요. `screens`의 실제 AWS 화면은 파일명 번호 순서가 실습 순서입니다. 대표 화면 몇 장만 고르지 말고 학생이 클릭하거나 상태를 확인하는 단계마다 사용하세요. 화면을 임의로 다시 만들거나 계정·리소스 값을 발명하지 마세요. NCS 코드는 학생용 본문에 반복 노출하지 말고 학습목표·체크포인트·발표자 노트에 연결하세요. 긴 명령어와 전체 화면 절차는 부록으로 분리하세요.

## 생성 결과 검수

- 실제 AWS 화면이 숫자 순서대로 반영됐는가?
- 화면이 너무 작아 콘솔 글씨를 읽을 수 없는 슬라이드가 없는가?
- 강의 내용과 화면의 서비스·메뉴가 일치하는가?
- 실패 → 원인 확인 → 수정 → 성공 화면이 생략되지 않았는가?
- 화면에 보이는 계정 번호, 사용자 이름, IP, 리소스 ID가 가려졌는가?
- 공식 문서 링크와 콘솔 이동 경로가 포함됐는가?
- 학생이 받을 파일·받는 곳·검증·수정·제출·복구 방법이 장표에 보이는가?
- 1주차에 팀 구성·역할 순환·팀 규칙·팀 파일 제출 절차가 포함됐는가?
- 마지막에 실행 중인 리소스의 중지·삭제 절차가 있는가?

> 화면은 2026-08-24 서울 리전에서 수행한 실습 기록이다. 당시 생성한 비용 발생 리소스는 정리됐으므로 라이브 서비스가 현재 실행 중이라고 표현하지 않는다.
