클라우드 MLOps 15주차 강의계획

한 줄 요약
"노트북 안의 모델을 주소를 가진 서비스로" -- 데이터 수집부터 학습.실험관리.컨테이너.API 서빙.자동배포.모니터링까지 한 줄기 파이프라인을 학생이 직접 관통하는 실습형 강의 (AWS 기반, 팀 프로젝트 18~20h, 15주)

주차별 강의계획

1주차  MLOps 개요 & 클라우드 첫걸음 -- 개인 S3 버킷 생성.CLI 조작, AWS 콘솔.IAM.리전 고정.Budgets 확인

2주차  리눅스 . EC2 개발환경 구축 -- EC2(t3.medium) 생성.SSH 접속.JupyterLab.boto3로 S3 연동

3주차  데이터 파이프라인 & 문제 정의 -- 공통 데이터 전처리 스크립트 작성(raw.processed), 팀 구성.문제정의서 초안.데이터 카드, 프로젝트 착수

4주차  베이스라인 모델 만들기 -- scikit-learn 파이프라인 학습.평가.model.pkl S3 저장, M1 문제정의서 제출

5주차  실험 관리 (MLflow) -- EC2에 MLflow 서버 구축(SQLite+S3), 하이퍼파라미터 5조합 실험 비교.등록 모델 생성

6주차  컨테이너 기초 (Docker . ECR) -- Dockerfile 작성.빌드.ECR 푸시.풀, 템플릿 기반 빈칸 채우기 방식

7주차  모델 서빙 API (FastAPI) -- /health /predict 구현.Swagger 테스트.모델+API 단일 이미지 빌드.ECR 푸시

8주차  배포와 데모 화면 . 중간 점검 -- ECR 이미지 EC2 배포.Streamlit UI 연동.외부 접속 데모, M2 중간 시연(팀별 5분)

9주차  프로젝트 통합 실습.보강 (신설) -- M2 후 파이프라인 전 구간 연결 점검.보완, 공통 파이프라인 재구축(실습A)+팀별 갭 메우기(실습B), 기술 부채 해소.전구간 체크리스트 통과(M2+)

10주차 관리형 ML 서비스 (SageMaker AI) -- SageMaker Studio 노트북.학습잡.엔드포인트 배포.즉시 삭제, 직접구축 vs 관리형 비교

11주차 생성형 AI 활용 (Amazon Bedrock) -- Bedrock 텍스트 생성 호출.프롬프트 실험, 프로젝트 보조용 LLM 엔드포인트 1개 추가

12주차 배포 자동화 (GitHub Actions) -- 팀 저장소 정리.브랜치.PR 경험, 템플릿 빈칸 채우기로 push.테스트.빌드.ECR.EC2 재배포 자동화, 발표 구성법 미니강의(문제.접근.결과.배운점 구조화) 병행

13주차 모니터링과 운영 -- CloudWatch Agent 로그.커스텀 메트릭.대시보드.알람 구성, 입력 데이터 드리프트 간이 모니터링.운영 체크리스트, M3 파이프라인 완성

14주차 프로젝트 자율 완성 -- 전구간 동작.재현성.MLflow.비용 최종 점검 후 README.시연 영상 백업 제출(강사 질의응답만 대기, 별도 코칭 없음)

15주차 최종 발표 및 마무리 -- 팀별 라이브 시연 15분+질의 5분.상호평가, 전체 리소스 정리(인스턴스.엔드포인트.ECR.S3).최종 비용 리뷰, 회고.포트폴리오 가이드
